## 🛠️ Tech Stack

- **Framework:** Next.js 14 (React, App Router)
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion + GSAP
- **Language:** TypeScript
- **Performance:** 60fps target, optimized
